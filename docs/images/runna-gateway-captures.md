# Runna Gateway screenshot provenance

These three curated images were captured from the public, fake-provider demo
during independent verification of the 2 October 2026 release. Runtime source:
`83409414bff1ed898b96e25891aaac570de8f314`. Each is an unaltered 1510 × 852
viewport capture; the full sticky-sidebar page is not stitched.

| Image | View |
|---|---|
| `runna-gateway-platform.png` | Dark Overview with the account menu open, both demo profiles available and platform viewer selected |
| `runna-gateway-northwind.png` | Light Overview after switching to the Northwind Health organisation viewer |
| `runna-gateway-login.png` | Public Explore sign-in with a dark left introduction and light right sign-in panel |

All records, organisations and displayed spending are synthetic. Public key IDs
are identifiers, not usable credentials; no API key, session cookie, prompt or
completion appears in these captures. The images document that verified release,
not continuous availability or measured production traffic.
